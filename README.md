# Clearstone Ventures LTD

A complete website rebuild for an emerging, privately held real estate investment and acquisition company. The site distinguishes current strategic interests from longer-term platform ambitions and makes no portfolio, performance, transaction or capital claims.

## Development

Install dependencies with `pnpm install`, start with `pnpm dev`, and build with `pnpm build`. The Next.js app exports a static production site to `out/`.

## Content and contact

The existing repository's contact address, `info@clearstone-ventures.com`, is retained. The inquiry form validates fields and opens an email draft; it does not transmit or store submissions. Confirm the mailbox before a public launch.

Property imagery is generated with the built-in image-generation tool and stored locally in `public/multifamily-community.jpg` and `public/franchise-nnn.jpg`. It is clearly labeled as illustrative and does not depict company assets, actual tenants or existing leases. No analytics or tracking scripts are included.

Image briefs: a landscaped, three-story garden-style multifamily community representing a 30+ unit acquisition focus; and a freestanding franchise-style quick-service restaurant with parking and a drive-through, illustrating NNN property strategy. Both exclude skyscrapers, tenant logos and actual lease claims.

Search metadata, sitemap and robots reference the intended domain, `https://www.clearstone-ventures.com`. A Sites review deployment does not configure or replace that domain's hosting.
